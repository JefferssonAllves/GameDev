# Raízes do Brasil

Nesta branch, abra `project.godot` no Godot e pressione **F5** para jogar **Estação do Vento**. Veja os controles no [guia do protótipo](raizes-do-brasil/README.md).

O projeto anterior, **Brasil em Retalho**, pode ser aberto em `brasil-em-retalho/project.godot`. Antes de executar pelo terminal, importe os recursos com `godot --headless --editor --path brasil-em-retalho --import`. Consulte o [guia da arena](docs/level-design.md) para os controles e testes desse projeto.
